Privacy Policy

Mac Documents Backup · Effective October 26, 2026

Purpose and operator

Mac Documents Backup is a personal-use utility maintained by the owner of the GitHub account semihozenc. It runs locally on the owner’s Mac using rclone to back up selected Documents files to the owner’s Google Drive.

Google data accessed and used

The utility requests the Google Drive drive.file permission to create and manage files it creates. It transfers selected file contents, names, folder structure and relevant metadata to the authorized Google Drive account. It checks backup files for changes and moves replaced versions into dated archive folders. Selected development files and secrets are excluded by local filter rules.

Storage, sharing and retention

Backup contents are stored in the owner’s Google Drive account. OAuth credentials and operational logs are stored locally on the Mac. No separate application server receives the backup data. The utility does not sell data, share it for advertising, or use it to train AI models. Google processes stored files under its own terms and privacy policy.

Backups and archived versions remain until the owner removes them. Deleting a local file does not automatically remove its cloud backup. Local logs may include file names and transfer status.

Control and security

The owner can stop the scheduled task, revoke access in Google Account settings, remove local credentials and logs, and delete backups directly in Google Drive. Transfers use encrypted HTTPS connections provided by rclone and Google APIs.

This website

This public documentation site does not contain backup files, OAuth secrets or tokens. It uses no application analytics, advertising or tracking scripts. GitHub Pages may process ordinary hosting request information under GitHub’s privacy policy.

Contact

Contact the maintainer through GitHub Issues. Do not post private files or credentials in public issues.
