Mac Documents Backup

A personal backup utility operated by the owner of the GitHub account semihozenc. It uses rclone on the owner’s Mac to copy selected Documents files to the owner’s Google Drive account.

Backups run daily. Development dependencies, Git directories, environment files and selected caches are excluded. Previous versions of replaced files are retained in dated archive folders. Deleting a local file does not automatically delete its cloud backup.

This is a private-use utility, not a service offered to the public. This website contains documentation only; it does not provide access to backup files or Google credentials.
